ゲームとデータについて

表示する確率は、Xの投稿から推測した未校正のモデル予測です。「信頼度」は根拠の充足度で、的中率ではありません。根拠不足時は参考値と表示し、取得失敗・期限切れでは確率を表示しません。最新の投稿と解析内容は Reset Watch で確認できます。

Reset Watch が Decisions API で「実施済み」と分類した、確信度80%以上のCodex全体向け告知をゲーム内の回復に使います。予告や予測確率では回復しません。実際のCodexアカウントの利用枠は変更しません。

データの取得が途切れた場合は、未確認期間の滅亡を確定せず、確認を待ちます。文明はこのブラウザに保存されます。データを消去した場合や別の端末では引き継がれません。体験モードは本番とは別のサンプルです。

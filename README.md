OpenAI社のTibo氏(Thibault Sottiaux / ティボー・ソティオ)は、自社の製品であるCodexのレートリミット（クレジット）の制限を解除する際に関連する投稿をXで行うことが知られている。また、現在(2026年10/18日時点)、OpenAIは28日間連続で新しいリリースを連続して行い、リリースがない日などにはレートリミットをリセットするキャンペーン(28 Days of Shipping)を行っている。そのため、Tiboの投稿する文章をOpenAI Decisions APIを用いて解析し、Codexの臨時使用枠リセットが行われるかを予測することができると考えた。

類似のコンセプトのWebサイトはすでに多く存在し、大抵の場合、パターン（4日おきという推測）や、ユーザーによる投票などを用いて予測しており、Tibo様が行われた投稿を解析し、リセットを推察するというアプローチは行われていないように見えたのがきっかけ。

注意：現時点では、OpenAI Decisions APIの予測は未校正であり、実際の的中率は未検証である。仮説に基づいた検証である。

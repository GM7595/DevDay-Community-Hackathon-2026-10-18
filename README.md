# Tibo Reset Watch

Tibo（[@thsottiaux](https://x.com/thsottiaux)）の公開投稿から、**Codexの臨時使用枠リセットを予測する**ハッカソンプロジェクトです。X公式APIで投稿・返信・画像を取得し、OpenAI Decisions APIで予告・実施報告・示唆を分類します。

関連ゲーム **「tiboっち : civilization」** では、実施済みと判定された告知がエージェント文明の利用枠を回復させます。予測を見る楽しさを、石器時代から未来文明まで育てる体験につなげます。

ゲーム画面でも、**24時間以内のリセット確率を大きく表示**し、根拠の充足度と解析時刻を添えます。元サイトの黒・蛍光ライム・ピンクのデザインとTiboの写真を引き継ぎ、予測を見てから文明の働き方を選べます。Xから推測する既存の処理は `tibo-reset/` にそのまま残しています。

## プロジェクト構成

| ディレクトリ | 内容 | 詳細 |
| --- | --- | --- |
| `tibo-reset/` | X公式APIによる収集、Decisions APIによる予測・投稿分類、保存データの更新スクリプト | [セットアップと仕様](./tibo-reset/README.md) |
| `cow/` | 「tiboっち : civilization」の単独Webゲーム、公開スナップショットとの連携、組み込み用コンポーネント | [遊び方と開発手順](./cow/README.md) |

各プロジェクトはリポジトリ直下の専用ディレクトリで開発します。ルートに共通の起動コマンドや依存パッケージはありません。

## 動かす

Node.js 22以上が必要です。

### 文明育成ゲームを遊ぶ

リポジトリのルートで実行します。追加のパッケージインストールやAPIキーは不要です。

```sh
npm --prefix cow run dev
```

[http://localhost:4173](http://localhost:4173) を開きます。ゲームはReset Watchの既存の公開スナップショットをサーバー経由で読み取り、プレイヤーごとにOpenAIやXのAPIを呼び出しません。ライブ連携には、そのスナップショットを取得できることが必要です。

「2分で体験」では、別の一時データを使って文明の成長・回復・滅亡を確認できます。体験モードのサンプル告知は本番の文明に影響しません。

### 投稿を収集・解析する

```sh
cd tibo-reset
npm ci

# 合成データからリクエストだけ作成する。外部APIは呼ばない。
npm start -- analyze --input examples/synthetic-posts.json \
  --as-of 2026-10-18T06:00:00Z --dry-run
```

実際の収集・解析には、`X_BEARER_TOKEN`（X公式APIのapp-only Bearer Token）と `OPENAI_API_KEY` が必要です。[設定手順](./tibo-reset/README.md#設定)に従い、Git管理外のローカル環境ファイルまたはホストのシークレットに設定します。キー・Cookie・環境ファイルをリポジトリへ追加しないでください。X Cookieや非公式APIによる取得は使用しません。

設定後、次のコマンドで直近100件を取得し、全体予測と投稿シグナルを解析します。

```sh
npm start -- run --count 100 --hours 24 --signals
```

## Decisions APIで判断すること

- **全体予測**：解析時点から24時間以内に臨時リセットが起きるかを推定します。投稿ごとのスコアの平均ではありません。
- **投稿の内容**：本文・画像・返信元・引用などから、予告、実施済み、示唆、否定、雑談などを区別します。画像が取得できなければ、解析済みや0%として扱いません。
- **時刻の根拠**：具体的な将来時刻の根拠がある場合だけ時間帯を推定します。過去の実施報告を次回リセットの予定に流用しません。
- **ゲームへの反映**：対象がCodexで、本人の実施済み告知と分類され、分類確信度が0.8以上などの条件を満たす投稿だけがゲーム内の枠を回復させます。高い予測確率や未来の予告だけでは回復しません。

全体予測、投稿シグナル、分類確信度は異なる数値です。いずれも実際の的中率を示すものではなく、予測は未校正です。対象は臨時リセットであり、通常の5時間・週次更新は含みません。

## 「tiboっち : civilization」の遊び方

働き方を選び、しばらくして街を見に戻ります。利用枠を使って研究を進めるほど、石器・農耕・王国・工業・情報・未来の6時代を発展します。

| 働き方 | 満タンから枠切れまで | 成長速度 |
| --- | --- | --- |
| 節約 | 7日 | 遅い |
| ふつう | 5日 | 標準 |
| 全力 | 3日 | 速い |

採用された実施告知で枠が100%に戻ります。0%になると仕事が止まり、その後24時間リセットがなければ滅亡します。**4日ごとにリセットが来る想定では、全力はちょうど限界、ふつうは余裕が残る**という駆け引きです。この4日間隔はゲーム設計・体験モードの仮定で、実際のリセット周期を保証するものではありません。

ブラウザを閉じている間も時刻と告知履歴から経過を再計算します。取得障害や履歴の欠落だけで滅亡を確定させません。滅亡した文明は記録として残り、その後の実施告知で次の世代を始められます。保存先は利用中のブラウザで、端末間共有はありません。

## ホスト先と統合状況

[Tibo Reset Watchのホスト先](https://tibo-reset-watch.soumame.chatgpt.site/)があります。ただし、`tibo-reset/README.md`では「現在は本人のみ閲覧」と案内されており、第三者への公開範囲は要確認です。

このチェックアウトには、予測サイトの `tibo-reset/site/` ソースがまだ含まれていません。そのため、サブプロジェクトに記載された `site:preview` や `site:export` は、このリポジトリだけでは実行できません。`cow/` の文明ゲームは単独で起動でき、サイトのソースがそろった後の組み込み手順も用意しています。**既存のホスト先にゲームが統合・公開された状態ではありません。**

## 検証と制約

文明ゲームのテストと公開用ビルドは、ルートから実行できます。

```sh
npm --prefix cow test
npm --prefix cow run build
```

ゲーム内の回復は公開告知のモデル分類に基づき、実際のCodexアカウントの枠を確認・変更するものではありません。同じ投稿の再取得は重複適用しませんが、同一のリセットを別の投稿で報告した場合の同一視は未対応です。取得可能な投稿範囲、欠けた文脈、モデルの誤分類にも影響されます。

非公式のファンプロジェクトであり、Tibo本人またはOpenAIによる提供・公認を示すものではありません。写真の出典と扱いは [cow/README.md](./cow/README.md#portrait-attribution) を参照してください。
